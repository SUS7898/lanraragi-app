# 실기기 수동 테스트 체크리스트 (TEST_CHECKLIST)

> 대상: Galaxy 폰 1대 + 태블릿 1대. **반드시 서명 릴리스 APK**(R8 minify 적용)로 수행한다.
> 결과는 `docs/PROGRESS.md` 검증 이력에 날짜·버전·기기와 함께 기록하고, 실패는 `docs/TROUBLESHOOTING.md`에.

## 0. 준비
- [ ] `v0.1.0` 태그 → Release 워크플로 성공 → `lrr-viewer-v0.1.0.apk`, `SHA256SUMS.txt` 확인
- [ ] (Galaxy) 설정 → 보안 및 개인정보 보호 → **자동 차단** 상태 확인(켜져 있으면 설치 전 끄기)
- [ ] LANraragi 서버 정보: 주소, API 키, No-Fun 모드 여부, "서버 측 진행률 추적" 설정 여부 메모

## 1. 설치 · 첫 실행
- [ ] 브라우저/파일앱에서 APK 설치 — "알 수 없는 앱 설치" 1회 허용, Play Protect 안내 확인
- [ ] 첫 화면이 서버 설정 화면인지. 잘못된 주소(`http://1.2.3.4:1`) → 연결 테스트가 이해 가능한 오류를 내는지
- [ ] 올바른 주소 + (필요 시) API 키 → 연결 테스트 성공 메시지(서버 이름·버전·아카이브 수)
- [ ] 저장 → 서재가 뜨고 썸네일이 보이는지(No-Fun 서버면 키 없이는 401 메시지가 나와야 함)
- [ ] 앱 강제 종료 후 재실행 → 설정 유지(API 키 복호화 정상)

## 2. 서재
- [ ] 스크롤 끝까지 → 다음 페이지가 이어서 로드(무한 스크롤), 중복 항목 없음
- [ ] 검색: 일반어, `artist:xxx`, `"따옴표 문구"`, `-제외어` 각각 결과 확인; 지우기 버튼
- [ ] 카테고리 선택/해제, 정렬 변경(추가일/제목/최근 읽음) + 오름/내림
- [ ] 신규만 / 미태그 / 완독 숨김 토글
- [ ] 당겨서 새로고침, 무작위(FAB) → 상세로 이동
- [ ] 탄코본(`TANK_`) 항목이 "묶음" 배지로 보이고 열면 수록 목록이 나오는지(서버에 탄코본이 있을 때)
- [ ] 비행기 모드에서 새로고침 → 스낵바/오류 화면, 복구 후 다시 시도 동작

## 3. 상세
- [ ] 메타데이터(페이지 수, 크기, 추가일), 태그가 네임스페이스별로 묶여 표시
- [ ] 태그 칩 탭 → 서재로 돌아가 해당 태그로 검색됨
- [ ] 목차(TOC)가 있는 아카이브: 항목 탭 → 해당 페이지로 리더 진입
- [ ] NEW 표시 토글(API 키 필요) 후 서재에서 배지 반영
- [ ] "웹에서 열기" → 브라우저로 서버 리더가 열림

## 4. 리더 — 페이지 넘김 모드(RTL/LTR/세로)
- [ ] 첫 페이지 로드, 스와이프로 넘김, RTL에서 방향이 맞는지(오른쪽→왼쪽), 슬라이더 방향도 뒤집혀 있는지
- [ ] 가장자리 탭 이전/다음, 가운데 탭 메뉴 토글, 탭 내비 끄면 전체가 메뉴 토글
- [ ] 핀치 줌 → 확대 상태에서 패닝이 되고 끝에 닿아야 페이지가 넘어가는지; 더블탭 줌
- [ ] 볼륨 키 이전/다음(설정 토글 후 끄면 볼륨 조절로 복귀)
- [ ] 화면 맞춤/가로 채움/세로 채움 전환, 배경색 전환
- [ ] 회전: 잠금 아이콘 토글, 회전 시 현재 페이지 유지
- [ ] 메뉴 숨김 시 시스템 바 숨김(몰입), 페이지 번호 오버레이 표시
- [ ] 아주 큰 페이지(4000px 이상) 선명하게 확대되는지(서브샘플링)
- [ ] 네트워크 끊고 다음 페이지 → 오류 + "다시 시도" → 복구 후 로드

## 5. 리더 — 웹툰 모드
- [ ] 연속 스크롤, 현재 페이지 번호 갱신, 슬라이더 점프
- [ ] 핀치 줌(1~3배)과 더블탭 복귀, 확대 중 세로 스크롤 유지
- [ ] **세로로 매우 긴 이미지(스트립)** 가 있는 아카이브: 빈 칸/깨짐 없이 표시되는지 → 문제 있으면 `BACKLOG P0-4`

## 6. 진행률 · 기록
- [ ] 몇 페이지 읽고 나가기 → 기록 탭에 항목/진행률, 상세의 "이어 읽기 (Np)" 표시
- [ ] 서버 진행률 추적이 켜진 서버: 웹 UI에서 진행률이 갱신되는지(1-based 페이지), 다른 기기에서 읽은 진행률로 이어 읽기
- [ ] "읽기 시작 시 NEW 해제" 동작, 끄면 유지
- [ ] 완독 후 다시 열면 처음부터 시작, "처음부터" 버튼
- [ ] 기록 항목 삭제, 전체 삭제

## 7. 설정 · 캐시
- [ ] 각 토글/선택이 즉시 반영되고 재실행 후 유지
- [ ] 평문 HTTP 허용 끄기 → http 서버 요청이 차단 메시지, 다시 켜면 복구
- [ ] 캐시 사용량 표시, 비우기 후 0에 가깝게; 캐시 크기 변경은 재시작 후 적용 안내
- [ ] 미리 불러올 페이지 수 0/3/10 변경 후 데이터 사용량/체감 확인

## 8. 자체 업데이트 (두 번째 릴리스 `v0.1.1` 필요)
- [ ] 설정 → 업데이트 확인 → "최신 버전" (v0.1.0만 있을 때)
- [ ] `v0.1.1` 태그 릴리스 후 확인 → 새 버전 카드, 릴리스 노트 표시
- [ ] 다운로드 진행률 → 검증 → "알 수 없는 앱 설치" 권한 요청(최초) → 설치 → 시스템 확인 화면 → 업데이트 완료
- [ ] 업데이트 후 설정·기록·캐시 유지, 버전 표시 갱신
- [ ] 세 번째 릴리스에서(앱이 설치자가 된 뒤) 확인 화면이 줄어드는지(Android 12+)
- [ ] 자동 확인: 24시간 뒤 또는 `lastUpdateCheck` 초기화 후 시작 시 다이얼로그
- [ ] (Galaxy) 자동 차단 켠 상태에서 설치 시도 → 어떤 오류가 나는지 기록 → `BACKLOG P0-3` 문구 반영

## 9. 네트워크 변형
- [ ] 리버스 프록시 하위 경로(`https://nas.example.com/lrr`) 서버 — 썸네일/페이지 URL 정상
- [ ] 자체 서명 HTTPS + 기기에 CA 설치 → 연결 성공; CA 없이 → TLS 오류 메시지
- [ ] Wi-Fi ↔ 모바일 데이터 전환 중 읽기(VPN/Tailscale 포함)

## 10. 안정성
- [ ] 리더에서 홈 → 다른 앱 여러 개 → 복귀(프로세스 종료 후 복원) 시 크래시 없음
- [ ] 저사양/구형 기기(Android 9)에서 설치·실행
- [ ] 1시간 연속 열람 후 메모리/발열 체감, 배터리
